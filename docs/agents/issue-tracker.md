# Rastreador de Tarefas (Issue Tracker)

Este projeto utiliza o **GitHub Issues** para gerenciar todas as tarefas, funcionalidades e bugs.

**Instruções para a IA:**
1. Quando a skill `to-tickets` (ou qualquer outra) for acionada para criar tarefas, você deve criá-las diretamente na aba "Issues" do GitHub deste repositório.
2. Utilize a ferramenta oficial de linha de comando do GitHub (GitHub CLI / comando `gh`) para ler e criar as tarefas no repositório (ex: `gh issue create`, `gh issue list`).
3. Cada ticket gerado deve ter um título claro, critérios de sucesso bem definidos e marcar dependências caso uma tarefa precise ser feita antes da outra.
4. Mantenha os textos no padrão Markdown para que fiquem bem formatados na interface visual do GitHub.
